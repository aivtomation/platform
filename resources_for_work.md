# Ресурси, які є оплачені для роботи.

## Google AI Pro: всі можливості

Google AI Pro — це розширений план від Google, який дає доступ до ШІ-функцій, підвищеної продуктивності та великого обсягу сховища.

### Що входить у Google AI Pro

- 5 ТБ хмарного сховища для Gmail, Google Диска та Google Фото.
- Додаток Gemini та інші функції ШІ.
- Розширений доступ до моделей Gemini 3.1 Pro.
- Доступ до Deep Research у Gemini.
- Higher access to Gemini 3 Pro in AI Mode for Google Search та до функцій Deep Search.
- Допомога Gemini в Google Docs, Sheets і Gmail.
- Підтримка творчих інструментів для зображень, музики й відео.
- Розширені можливості для NotebookLM.
- Підвищені ліміти в AI Studio.
- Підвищені ліміти в Gemini CLI, Gemini Code Assist IDE та інструментах для розробки.
- Щомісячні кредити Google Cloud на 10 USD для Google Developer Program.
- Сімейний доступ до 5 користувачів.

### Для чого це корисно

- Для роботи з документами, таблицями та поштою.
- Для створення й аналізу контенту через Gemini.
- Для досліджень через Deep Research.
- Для розробки з використанням Gemini CLI, Code Assist і AI Studio.
- Для зберігання файлів у великому хмарному сховищі.

### Примітка

Деякі функції можуть відрізнятися залежно від країни або бути доступні лише в окремих регіонах.




## Хостинг на Hostinger тариф "Business"

Тариф "Business" розроблений для користувачів, яким потрібні розширені інструменти та ресурси для активного розвитку онлайн-проєктів.

### Основні характеристики та ресурси
- **Кількість сайтів:** до 50 сайтів.
- **Дисковий простір:** 50 ГБ NVMe.
- **Оперативна пам'ять:** 3 ГБ.
- **Ядра CPU:** 2.
- **PHP Workers:** 60.
- **Файли та каталоги (іноди):** 600 000.
- **Бази даних:** 150 (обсяг бази даних до 3 ГБ).
- **Трафік:** необмежений.

### Ключові переваги та інструменти
- **Продуктивність:** швидкий SSD-диск стандарту NVMe, безплатна CDN (Content Delivery Network).
- **Підтримка WordPress:** керований хостинг для WordPress, помічник ШІ для WordPress, підтримка WooCommerce, WordPress Multisite.
- **Штучний інтелект:** 30 кредитів для конструктора сайтів ШІ, можливість створення інтернет-магазину за допомогою ШІ, створення готових сайтів WordPress за допомогою ШІ.
- **Розробка:** підтримка 5 керованих вебзастосунків Node.js.
- **Безпека та бекапи:** щоденні бекапи (та бекапи за запитом), необмежені безплатні SSL-сертифікати.
- **Пошта:** 5 безплатних поштових скриньок на сайт (безплатно на 1 рік).
- **Додатково:** безплатний домен (при реєстрації на 1 рік), безплатний email-маркетинг (на 1 рік), безплатна автоматична міграція сайтів.

### Додаткові переваги
- Аптайм 99,9%.
- Глобальні дата-центри.
- Інтуїтивна панель керування.
- Онлайн-підтримка 24/7.
